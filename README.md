\# Smart Network Optimization Using MST and Shortest Path Algorithms



\## Project Overview

A Python-based Data Structures and Algorithms project that demonstrates graph optimization using Minimum Spanning Tree algorithms and shortest-path analysis through an interactive dashboard.



\## Algorithms Implemented

\- \*\*Kruskal's Algorithm:\*\* Finds a Minimum Spanning Tree (MST).

\- \*\*Prim's Algorithm:\*\* Finds a Minimum Spanning Tree (MST).

\- \*\*Dijkstra's Algorithm:\*\* Finds shortest paths in a graph.



\## Technologies Used

\- Python

\- Streamlit

\- NetworkX

\- Matplotlib

\- Pandas

\- NumPy



\## Project Structure

\- `algorithms/` — Algorithm implementations

\- `graph/` — Graph generation and logic

\- `visualization/` — Graph visualization

\- `data/` — Input data

\- `results/` — Performance results and graphs

\- `screenshots/` — Project screenshots

\- `app.py` — Streamlit application

\- `performance\_results.csv` — Algorithm performance results

\- `requirements.txt` — Python dependencies



\## Installation and Usage



Install dependencies:



`python -m pip install -r requirements.txt`



Run the application:



`python -m streamlit run app.py`



\## Project Objectives

\- Understand graph algorithms and their applications.

\- Analyze minimum-cost network design.

\- Calculate shortest paths.

\- Compare algorithm performance.
